QUICK START (5 minutes):
1. Open the PDF for YOUR paper size.
2. Print page 1 (Dashboard) + ONE tracker (pages 2-7).
3. Printer setting: "Actual size" / 100% (not "Fit to page").
4. Fill in your goal + start date, save week 1, color a box. Done!

EXCEL BONUS:
- Open in Microsoft Excel, or Google Sheets via File > Import > Upload.
- Log savings in column D of ONE challenge tab; the Dashboard sums it all.

TIPS:
- Any order counts: do small weeks when tight, big weeks when flush.
- 32 lb / 120 gsm paper or cardstock lasts all year in a binder.
- Laminate the Dashboard + use dry-erase markers to reuse it yearly.
- Pair trackers with labeled envelopes to cash-stuff each week.
